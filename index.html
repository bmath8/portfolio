CASE 02 — 2026

Super Bowl LX Squares real-time web app that ran a live event

A squares pool that real people used during a real game. 100 squares, live random draw, and score-driven winner resolution updating for everyone at once while the game was actually on.

My role
Sole builder — and the person on the hook when it had to work in front of an audience, live, with no second chance.
Problem & decisions
  • An event app has exactly one moment to be correct. The draw had to be verifiably fair and identical for every viewer, so state is resolved centrally and pushed out rather than computed per client.
  • Deployed as a static front end with no build step — the fewer moving parts on game day, the fewer ways it fails.
