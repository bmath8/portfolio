03

Incident reports

real outages, really fixed — the part most portfolios can't show
SEV-1 · RESOLVED

The fleet went silent

Symptom
Zero messages delivered. Everything "looked" healthy.
Root cause
Two compounding bugs: a Windows cp1252 decode failure silently emptied cron output, and the self-heal regex matched "NOT running" — so recovery never fired.
Fix
UTF-8 enforced at the gateway, process-based liveness checks, and a delivery-verification watchdog. Test suite grown to catch the class, not the bug.
SEV-1 · RESOLVED

Host VM died nightly

Symptom
The whole fleet dead every morning, no crash logs.
Root cause
A documented WSL VM teardown bug (microsoft/WSL #13416) killing the VM overnight.
Fix
Migrated the entire system to native Windows in one day — removing the failure class, not patching around it. WSL kept as a disabled fallback.
SEV-2 · RESOLVED

Vendor update broke delivery — twice

Symptom
Agent-host updates kept breaking Telegram delivery.
Root cause
Update swapped the shared engine under the running gateway.
Fix
Made delivery update-proof (direct Bot API self-send) and built a guarded upgrade path: backup → update → verify → auto-rollback. Latest host upgrade shipped with zero downtime.
