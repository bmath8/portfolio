SEC. 03

Incident reports

Real production failures, diagnosed and engineered away — the section most portfolios can't write

Resolved
INCIDENT FORM 20-ASEV-1

The fleet went silent

Zero messages delivered; everything "looked" healthy.
Two compounding bugs: a Windows cp1252 decode failure silently emptied cron output, and the self-heal regex matched "NOT running" — recovery never fired.
UTF-8 enforced at the gateway; process-based liveness checks; a watchdog that verifies delivery, not just execution. Tests grown to catch the class.
Resolved
INCIDENT FORM 19-BSEV-1

Host VM died nightly

Whole fleet dead every morning; no crash logs.
A documented WSL VM teardown bug killing the virtual machine overnight.
Migrated the entire system to native Windows in one day — removed the failure class rather than patching around it.
Resolved
INCIDENT FORM 23-CSEV-2

Vendor update broke delivery — twice

Agent-host updates kept breaking message delivery.
Updates swapped the shared engine under the running gateway.
Delivery made update-proof (direct API self-send) + a guarded upgrade path: backup → update → verify → auto-rollback. Latest host upgrade: zero downtime.
