02 — Operations

It broke. I fixed it. Here's proof.

Anyone can demo a happy path. These are real production incidents from my own system — root-caused, documented, engineered away. It's the part of the job most portfolios can't show.

SEV-1 · RESOLVED

The fleet went silent

Zero messages delivered — while everything looked healthy.

Two compounding bugs: an encoding failure silently emptied cron output, and the self-heal regex matched "NOT running", so recovery never fired.

Fix: UTF-8 enforced, process-based liveness, a watchdog that verifies delivery — and tests that catch the class, not the bug.

SEV-1 · RESOLVED

Host VM died nightly

The whole fleet dead every morning. No crash logs.

Root cause: a documented WSL VM teardown bug killing the virtual machine overnight.

Fix: migrated the entire system to native Windows in one day — removed the failure class instead of patching around it.

SEV-2 · RESOLVED

Vendor update broke delivery — twice

Host updates kept swapping the engine under the running gateway.

Fix: delivery made update-proof (direct API self-send) plus a guarded upgrade path — backup → verify → auto-rollback. Latest upgrade: zero downtime.
