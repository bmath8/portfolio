# Project Brief — Portfolio Site

## Project
A single-page personal portfolio site for Brian Mathew, linking projects, skills, and contact.

## Product goal
The hub recruiters visit — clean, fast, mobile-friendly; put on resume, LinkedIn, and every application.

## Tech stack
- Frontend: single static `index.html` (inline CSS, Google Fonts). No build step, no backend.

## Key architectural decisions
- Static + self-contained for trivial, free deployment (Vercel or GitHub Pages).

## Constraints
- Fill in: LinkedIn URL, live demo links per project, optional screenshots.

## Definition of done
- Deployed live; LinkedIn + project demo links filled; URL added to resume/LinkedIn/GitHub.
