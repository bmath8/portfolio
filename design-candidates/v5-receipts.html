03

The day it broke

What I actually did, in order
Outcome
03.1

A process guardian failed silently and filled the disk. Nothing alerted me, because the thing whose job was to notice was the thing that died.

I traced it to root cause, got the machine back, and then wrote the check that catches it next time. That last part is the part I actually care about — an incident you don't learn from is just a bad day.

  1. Symptom Disk at capacity. Agents failing on write.
  2. Trace Guardian process gone. No crash, no non-zero exit, no alarm.
  3. Root cause The watcher had failed silently — the workload was fine.
  4. Recovery Reclaimed the disk, brought the machine back to running.
  5. Fix Wrote a health check that fails loudly when the guardian is absent.
  6. State That check is in the fleet now, running on schedule with the rest.
Result A failure mode that used to be invisible is now noisy. Ask me about this one in the interview — it's my favorite thing to talk about.
