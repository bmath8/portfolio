Brian OS

operating sole architect · Python / Ollama / Windows

A 25-agent fleet that runs my life on my own hardware. Scheduled agents prepare a morning brief, watch the machine, draft work overnight, and track the job hunt — all on a local LLM, so it costs nothing per run and never leaves the box.

The interesting part isn't the agents, it's the operations: a watchdog that detects a dead gateway and restarts it, structured state so a crashed run resumes cleanly, and draft-only guardrails that require my approval before anything sends, spends, or deletes.

AI Job Hunter

in development sole builder · Python / Flask

A job-search platform that tailors resumes without inventing a fact. It reads a posting, scores keyword coverage against a base resume, and surfaces the gaps — then drafts a cover letter and tracks the application.

The design constraint is the whole point: AI tailoring tools drift into fabrication, so every generated claim is validated against a verified evidence base before it can appear in output. Generation, matching, and tracking are separate components, so a failure in one can be isolated and tested alone.
